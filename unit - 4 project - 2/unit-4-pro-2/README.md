# Jai Ananth — Cloud Nexus Portfolio

A React + Vite single-page portfolio project with six client-side routes using React Router DOM.

## Pages
- Home
- About
- Introduction
- Projects
- Skills
- Contact

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes
The project intentionally uses React functional components and CSS instead of a large UI library. The contact form is front-end only and can be connected to a backend or email service later.
